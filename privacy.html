Privacy Policy

This application is for personal use only and is used solely by its owner to access the owner's own Google Drive account.

Data

It accesses Google Drive files of the owner's own account only to back up and synchronise them. No data is collected from any other person.

Sharing

No data is sold, shared with, or transmitted to any third party, analytics service or advertiser. Data moves only between the owner's Google Drive and the owner's own devices.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in the Google Account security settings.
